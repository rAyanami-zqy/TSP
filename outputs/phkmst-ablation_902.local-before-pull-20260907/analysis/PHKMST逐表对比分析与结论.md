数据源：`/Users/a/Ayanami/code/TSP/outputs/phkmst-ablation`。本报告对应同目录的 [逐实例 HTML 表](./PHKMST逐实例消融对比表.html)。

## 分析口径

- 完成数与独占实例使用全部 50 个实例；超时不进入运行时间和分支数的配对比值。
- 时间与分支变化均表示配置 B 相对配置 A；负数为下降（改善），正数为上升（退化）。
- 几何平均和中位数描述逐实例典型趋势；累计变化使用共同成功集的总量，容易被困难实例主导。
- 分支几何平均使用 `(B+1)/(A+1)-1`；累计分支变化直接比较分支创建数总和。
- 代表性实例只列出绝对变化至少 0.01% 的项目，避免把极小数值差异当成实质现象。
- 时间只有一次重复且配置内部并行运行，细小时间差应视为噪声；分支数通常更稳定。

## 最终汇总结论与建议

- 所有配置在成功求解的实例上均与 Concorde 结果一致，当前差异主要体现在完成覆盖、运行时间和分支创建数。
- 核心势策略中，建议优先采用 P1，即根节点 Polyak、搜索节点 Polyak 和 subtree-adaptive 持久势更新。P1 相比 P0 明显压缩搜索树并增加一个完成实例；P2 和 H2 的节点 Helsgaun 均未表现出替代节点 Polyak 的依据。
- 根势策略存在实例互补性。P1 适合作为均衡的主配置；H1 可用于困难实例的补充求解或失败重试，但不建议直接全面替换 P1。
- 临时节点势更新中保留 T1 的 depth=1；T2 会扩大搜索树，T3 与 T1 整体接近。T4 的持久子树 epoch 更适合困难实例主导的批次，不建议完全替代 T1。
- α 分支策略应采用降序。局部候选范围优先 B2；全局候选范围使用 B4，且 B4 仅作为特定困难实例的补充。B1 和 B3 不建议继续作为默认候选。
- 与默认权重顺序 P0 直接比较时，B2 新增两个完成实例且没有丢失实例，但共同成功实例的累计时间基本持平；B4 新增两个完成实例但丢失 gr137，收益主要集中在少数困难实例。因此 B2 和 B4 更适合作为覆盖增强或超时重试策略。
- 当前建议的组合求解顺序为 P1 主求解，超时后依次尝试 H1 和 B2；若已知实例在全局 α 降序下受益，再补充 B4。任何单一配置仍至少有 18 个实例超时，因此组合求解比只保留一个配置更稳妥。
- P1 与 B2 的策略收益来自不同消融组，现有数据不能证明二者可以直接叠加。下一步应单独测试“P1 + 局部 root-α 降序”，并采用多轮、固定并发条件复测后再决定是否设为最终默认配置。
