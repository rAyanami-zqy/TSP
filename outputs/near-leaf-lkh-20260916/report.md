# 节点势上升倒置深度门槛 + LKH 探索

配置为当前 hybrid-reverse/subtree-adaptive-32，LKH tour + PI warm start，
实例为 eil101、gr96、pr124、kroC100、u159。倒置门槛定义为：当前已 forced
边距离 tour 所需的 n 条边只差不超过 `skip-last-edges` 时，不再执行节点势上升。

| 0 | 16 | 2.551139 | 4,781 | 13,762 | 0 |
| 0 | 24 | 2.491187 | 4,781 | 13,762 | 0 |
| 0 | 32 | 2.523217 | 4,781 | 13,762 | 0 |
| 0 | 40 | 2.541283 | 4,781 | 13,762 | 0 |
| 0 | 48 | 2.553422 | 4,781 | 13,762 | 0 |

| 0 | 80 | 2.529196 | 32,840 | 12,606 | 28,323 |

| 0.0001 | 16 | 1.836087 | 14,809 | 16,557 | 0 |
| 0.0001 | 24 | 1.834345 | 14,809 | 16,557 | 0 |

| 0.0001 | 64 | 1.836405 | 17,487 | 16,328 | 2,893 |
| 0.0001 | 80 | 1.891203 | 115,488 | 13,214 | 103,657 |

`1..48` 条的门槛没有命中任何节点，说明这些实例在真正接近凑满 tour 边之前
已经由下界或不可行性剪掉；不存在一批仍在做势上升的传统“最后几层”可供省略。
门槛提高到 64 才开始命中，但不比基线快；80 会明显扩大搜索树，尤其与
gap-change 组合时 expanded 从 14,809 增至 115,488，总时间回退约 3.9%。

因此该倒置门槛保留为实验参数，默认 0 关闭。当前五实例结果不支持启用它。
