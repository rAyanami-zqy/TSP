# HKMST 与 LKH 论文 1-tree 上升策略对照

## 结论

当前 HKMST 的固定根 Polyak 上升仍应作为默认策略。25 个根节点实验中，
Polyak 下界逐例强于从零开始的 Helsgaun 论文式调度；9 个可完整求解实例中，
论文式调度合计创建节点增加 185.59%，展开节点增加 182.41%。

两种思想可以安全结合，但本轮的 `Polyak -> Helsgaun` 精修不适合默认开启：
它只在 `dantzig42` 和 `att48` 的初始根下界上继续提升，9 个完整搜索实例
合计创建/展开节点仍分别增加 1.77%/1.84%。保留为可选实验策略更合适。

## 对照策略

四种策略共享同一个受约束 HKMST、同一个启发式上界和同一个 BP 搜索：

| CLI | 含义 |
|---|---|
| `--hk-ascent none` | 不使用顶点势，即原始固定根 1-tree |
| `--hk-ascent polyak` | 当前 HKMST 默认；`t = alpha(UB-w)/||g||^2`，停滞后缩小 `alpha` |
| `--hk-ascent helsgaun` | 论文式 period、步长减半和 `0.7g(k)+0.3g(k-1)` 平滑方向 |
| `--hk-ascent hybrid` | 先运行 Polyak，再从其最佳势出发做 Helsgaun 精修；只保留下界更强的一组势 |

所有策略都只在根节点改变势。进入搜索前固定

```text
d(i,j) = c(i,j) + pi[i] + pi[j]
```

随后所有 1-tree 成本统一减去 `2*sum(pi)`。因此候选权重顺序在整轮 DFS
中不变，当前 decremental dynamic MST 的 replacement 正确性前提仍成立。

### 与论文完整实现的边界

本实验复现论文的下界变换、period/步长策略和平滑次梯度，但固定特殊节点
为 0。论文还会从 MST 叶节点中动态选择特殊节点；当前 HKMST 把根的两条边
与内部 MST 分开维护，搜索期间切换特殊节点会改变动态状态语义，不能直接复用。

因此这里比较的是“适配当前 HKMST 的论文上升策略”，不是对完整 LKH
候选集和可变特殊节点实现的否定。论文的调度也以改善 alpha-nearness 为主要
目的，而当前实验首先衡量分支定界下界和 BP 搜索树。

## 根下界实验

复现清单：`data/classic/batch-hk-ascent.txt`。命令示例：

```sh
./build/tsp_bb --exact-max-n 200 --root-bound-only \
  --hk-ascent polyak --batch data/classic/batch-hk-ascent.txt
```

`--root-bound-only` 仍先计算同一启发式上界，然后建立根势和根 1-tree，
但不进入精确 BP 搜索。输出的 `cost/tour` 只是可行上界，不是最优证明。

### 汇总

| 指标 | Polyak | Helsgaun | Hybrid |
|---|---:|---:|---:|
| 对 Helsgaun 的逐例下界胜负 | 25 胜 | 0 胜 | - |
| 从原始 1-tree 到共同上界的平均 gap closure | 90.84% | 89.31% | 90.92% |
| 25 例上升阶段总时间 | 0.765 s | 0.402 s | 1.018 s |
| 平均 1-tree 迭代数 | 214.2 | 94.7 | 269.4 |

Helsgaun 调度的上升阶段约比 Polyak 少 56% 的迭代并快 47%，但本组实例的
最终下界一致偏弱。Hybrid 比 Polyak 多约 33% 上升时间。

## 完整精确搜索

节点数是确定性指标。计时仅作本机单次诊断，没有用来替代节点统计。

| 实例 | 最优值 | Polyak created/expanded | Helsgaun created/expanded | Hybrid created/expanded |
|---|---:|---:|---:|---:|
| st70 | 675 | 176651 / 121714 | 202822 / 139410 | 176651 / 121714 |
| eil76 | 538 | 162489 / 121189 | 189325 / 133990 | 208794 / 156623 |
| rat99 | 1211 | 49944 / 37385 | **35109 / 27287** | 49944 / 37385 |
| eil101 | 629 | 2210554 / 1630895 | 6995856 / 5096010 | 2210554 / 1630895 |
| dantzig42 | 699 | 11 / 7 | 137 / 94 | **8 / 8** |
| att48 | 10628 | 538 / 414 | 2486 / 1721 | **157 / 122** |
| bayg29 | 1610 | 3 / 3 | 3 / 3 | 3 / 3 |
| bays29 | 2020 | 15 / 11 | 213 / 150 | 15 / 11 |
| fri26 | 937 | 1 / 0 | 1 / 0 | 1 / 0 |
| **合计** | - | **2600206 / 1911618** | 7425952 / 5398665 | 2646127 / 1946761 |

相对 Polyak：

- Helsgaun: created `+185.59%`，expanded `+182.41%`；
- Hybrid: created `+1.77%`，expanded `+1.84%`。

这也说明标量根下界不是唯一性能因素。顶点势还会改变：

- 全局候选边排序；
- 根 reduced-cost fixing；
- 违规度顶点和 BP 边选择；
- 后续 replacement 顺序。

所以更高的根下界可能对应更差的搜索树。`eil76` 中 Hybrid 的最终根下界
略强于 Polyak，但展开节点反而增加；`rat99` 中 Helsgaun 下界略弱，却减少
了约 30% 节点。

## 推荐的结合方向

后续已实现“搜索节点局部势更新证书”，并验证 adaptive 触发可以显著缩小
搜索树；实现与结果见
`docs/HKMST-node-potential-update-experiment-2026-08-06.md`。它不改变本报告
关于根上升策略的结论：根节点仍默认 Polyak，节点更新是独立的可选层。

1. 默认继续使用 Polyak，保证当前整体性能不回退。
2. 保留 `helsgaun` 和 `hybrid` 作为运行时实验选项，不改变默认结果。
3. 若继续融合，优先研究“搜索树感知”的选择标准，而不是只比较根下界：
   可同时考虑 reduced-cost 固定边数、根 1-tree 的总度数违规和首层 BP
   分支规模。
4. 一个更保守的组合是：用 Helsgaun 精修只生成额外根证书；若它已经达到
   incumbent 则根剪枝，否则仍用 Polyak 势进入搜索。这样不会恶化后续
   HKMST 搜索树，但只有跨过剪枝阈值时才有收益。
5. 可变特殊节点需要单独实验。可先在根上枚举/选择特殊节点并重建一次固定
   root 状态，而不是在 DFS 中动态切换；确认收益后再决定是否重构 HKMST。

## 正确性验证

- Release CTest: 4/4 通过；
- 新增策略回归验证：各下界不超过穷举最优值，Polyak/Helsgaun 不弱于零势
  起点，Hybrid 不弱于其 Polyak warm start；
- `helsgaun` 和 `hybrid` 分别与独立 Held-Karp 动态规划对拍 10 个完整随机图
  和 6 个稀疏随机图，均为 `ok=16, failed=0`；
- 上表 9 个经典实例三种策略均返回相同已知最优值。
