## 六、关键结论

1. **tsp_bb 在所有共同实例上显著优于 tsp_bb_old**，加速比 8.4× 到 37.2×，节点数缩减 1.7× 到 8.1×

2. **bayg29 是最重要的对比点**：
   - tsp_bb：33.7s 找到最优解 1610，创建 12.7M 节点
   - tsp_bb_old：20.9min 找到最优解 1610，创建 103.5M 节点
   - 即使 old 有 1h 超时（vs 30min），tsp_bb 仍快 37×

3. **wi29 (n=29) 和 dj38 (n=38) 秒级解决**，说明瓶颈在实例结构（下界 gap）而非规模：
   - wi29: 215ms, gap=17.7%, 78K 节点
   - dj38: 117ms, gap=5.6%, 26K 节点
   - 对比 bays29: 同为 n=29, 1h 超时

4. **ulysses22 是共同瓶颈**：n=22 却两版均超时，是下一步优化的首要目标

5. **与 Concorde 的差距**：Concorde 毫秒级解决所有 n≤52 实例；根本差距在下界质量（1-tree vs LP relaxation）
