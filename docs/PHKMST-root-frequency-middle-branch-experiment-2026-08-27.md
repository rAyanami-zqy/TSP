# PHKMST 根多 1-tree 频率中间分支实验

## 目标

验证一种接近 LP middle branching 的低成本分支先验：不额外求解 LP，也不为
搜索节点增加新的 1-tree 构造，而是复用根 Held-Karp 势上升已经产生的多棵
1-tree，把边在这些树中的出现频率当作近似分数。

显式实验选项为：

```text
--branch-edge-order root-frequency-middle
```

默认 `--branch-edge-order weight` 不受影响。

## 实现策略

根势上升每得到一棵可行 1-tree，就把其中恰好 `n` 条边的计数加一。若共得到
`S` 个样本，边 `e` 出现 `C(e)` 次，则近似频率为：

```text
p(e) = C(e) / S
```

BP 每轮仍先找当前 1-tree 的最大度违规值，并只保留至少连接一个该度数顶点
的未决树边。在这些热点候选中优先选择最接近 `p=1/2` 的边。实现不做浮点
除法，而最小化完全等价的整数距离：

```text
frequency_distance(e) = |2*C(e) - S|
```

频率距离相同时，依次优先：

1. 两端超度覆盖量更大；
2. adjusted-weight 更小；
3. 规范化端点字典序更小。

根频率只在选中该策略时分配 `n*n` 计数表。根重启会清空并重新收集；搜索
节点和 subtree 势 epoch 不更新这份静态先验。若根势上升被关闭、数值保护
阻止上升或没有可行样本，则自动回退默认分支边比较器。

## 正确性与额外成本

该策略只改变 `bpPartition()` 选择树边的顺序，不修改：

- forced/forbidden 可行域；
- Kruskal 或 Prim 的 1-tree 下界；
- 增量 forbid replacement；
- BP 的互斥分支覆盖关系；
- 正式剪枝条件。

根上升本来就要生成这些 1-tree，因此没有增加 1-tree 构造次数。新增成本是
仅在实验模式下记录每轮 `n` 个 edgeId，以及 BP 中读取整数计数。`st70` 和
`eil101` 的根 Polyak 上升分别产生 396 和 400 个频率样本。

## 开启 subtree-adaptive 节点势更新

配置：gap 2.05%、epoch 层距 1、单次最多 16 轮、预算 5000。九实例为
dantzig42、att48、bayg29、bays29、fri26、st70、eil76、rat99 和 eil101。
同一 Release 二进制交错运行七次，wall 取中位数。

| 分支顺序 | wall 中位数 | created | expanded | 势尝试 | 势迭代 |
|---|---:|---:|---:|---:|---:|
| weight | **0.85 s** | **161,702** | 100,660 | **2,550** | **19,984** |
| root-frequency-middle | 0.95 s | 180,564 | **100,652** | 3,810 | 29,361 |

根频率的 expanded 仅减少 8（-0.008%），created 增加 11.66%，wall 增加
11.76%。势尝试和势迭代分别增加 49.41% 和 46.92%。

主要变化不是总展开量，而是热点迁移：

| 实例 | weight created / expanded | root-frequency created / expanded |
|---|---:|---:|
| st70 | 690 / 240 | 177,883 / 100,292 |
| eil101 | 160,212 / 100,177 | 1,739 / 231 |

频率策略几乎把困难从 `eil101` 转移到 `st70`。这说明根样本包含的“不确定性”
信号具有强实例依赖性；相同的静态排序无法稳定预测深层受约束子树。

## 关闭搜索节点势更新

仍保留相同的根 Polyak 势和根频率，只把搜索节点势策略设为 `none`。同一
九实例交错运行三次，wall 取中位数。

| 分支顺序 | wall 中位数 | created | expanded |
|---|---:|---:|---:|
| weight | **3.75 s** | **2,600,206** | **1,911,618** |
| root-frequency-middle | 52.16 s | 53,589,140 | 30,408,009 |

根频率使 created 放大 20.61 倍、expanded 放大 15.91 倍、wall 放大
13.91 倍。主要热点包括：

| 实例 | weight created / expanded | root-frequency created / expanded |
|---|---:|---:|
| st70 | 176,651 / 121,714 | 22,512,142 / 12,680,839 |
| rat99 | 49,944 / 37,385 | 13,901,116 / 7,811,685 |
| eil101 | 2,210,554 / 1,630,895 | 16,955,093 / 9,790,423 |

因此退化不是自适应势触发本身造成的。节点势在第一组实验里只是大幅压住了
错误排序产生的搜索树，并造成 `st70`/`eil101` 热点互换。

## 结论

1. 复用根势上升多棵 1-tree 的频率在工程上很便宜，并能与现有增量 1-tree
   安全共存；
2. 静态 `p≈0.5` 不是可靠的全树主分支指标，当前九实例总体回退；
3. 所有上升轮次被等权统计，早期离最优势较远的过渡树也进入频率，是一个
   明显噪声来源；
4. 根频率没有反映当前 forced/forbidden 状态，搜索越深，先验越陈旧；
5. 默认策略继续使用 `weight`，该实现只保留为显式实验选项。

如果继续这一方向，更合理的第二步不是直接扩大样本，而是只统计根上升末段
或接近最佳根下界的 1-tree，并把频率作为候选接近时的平局规则；在证明静态
信号稳定前，不应为每个搜索节点重新采样。

## 验证

- 新增频率收集不变量：每个可行样本恰好累计 `n` 条边；
- 新策略在小实例上与穷举最优值一致；
- CTest 4/4 通过；
- 九个经典实例在两种节点势配置下均返回相同已知最优值。
